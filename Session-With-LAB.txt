    https://rol.redhat.com [Use RedHat Login ID]

  - Access to "LAB" -> Click on "OPEN CONSOLE" w.r.t workstation.
  - CLick on "Terminal" and access OCP cluster from workstation node.
  - Login to OCP cluster via CLI.
    Example:-
    $ oc login -u admin -p redhatocp https://api.ocp4.example.com:6443 
    $ oc whoami 
    $ oc whoami -t 
    $ oc version 
    $ oc get nodes 
    $ oc get clusterversion 

  - Login to OCP cluster via WebConsole.

    https://console-openshift-console.apps.ocp4.example.com

Step-2# Create Secret "name=secret-sre".
 $ oc create secret generic secret-sre --from-file htpasswd=htpasswd-sre-file -n openshift-config 
 $ oc get secret -n openshift-config
 $ oc get secret secret-sre -n openshift-config
 
 $ oc get secret secret-sre -n openshift-config -o yaml
 $ oc get secret secret-sre -n openshift-config -o yaml > secret-sre.yaml 
 or
 $ oc get secret secret-sre -n openshift-config -o json 
 $ oc get secret secret-sre -n openshift-config -o json > secret-sre.json
