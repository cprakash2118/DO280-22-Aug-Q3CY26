 - Authentication w.r.t OpenShift.
   1) "Token" Based authetication 
       OAUTH -> OpenShift-APiserver -> Kube-apiserver 
   
   2) "Client Certificate" based authetication
       Client Certificate -> kube-apiserver     
   
   1) "Token" Based authetication
       - Token based authetication via OAuth service.
	   - OAuth service is an identity Broker (Deal with Identity Providers "IdPs" on behalf of OpenShift).
	   - IdP's htpasswd, LDAP, AD, OPenID connect etc. 
   
       $ oc login -u admin -p redhatocp https://api.ocp4.example.com:6443 
	   $ oc whoami 
	   admin 
	   $ oc whoami -t 
	   akjsdhjsadhkjas98798766hashdjkaso
	   
	   Token = userName + Password.
	   
	   $ oc login --token=akjsdhjsadhkjas98798766hashdjkaso --server=https://api.ocp4.example.com:6443
