 Authentication w.r.t OpenShift:-
 1-) Token Based authentication
 2-) Client Certificate Based authentication
 
- Token Based authentication
  - OAuth used for token based authentication w.r.t OpenShift.
  - OAuth is cluster-service w.r.t OpenShift.
  - OAuth is an Identity Broker (ON behalf of OpenShift, OAuth sync with Identity Providers "IdPs").
  - Once authentication successfully done, then OAuth provides token.
  - Identity Providers used for authentication like:-
    1- htpasswd  [do280]
	2- LDAP      [do280 additonally]
	3- Active Directory (AD)
	4- OpenID Connect (OIDC) - AWS IAM, PingIdentity etc 
	5- keystone etc

Task-01# How to create openshift's user and login to OCP cluster?
Step-1 - Create local database (User's details).
   $ htpasswd --help 
   $ htpasswd -c -b -B htpasswd-file-upload-anyname user1 redhat 
   $ htpasswd  -b -B htpasswd-file-upload-anyname user2 redhat
   $ htpasswd  -b -B htpasswd-file-upload-anyname user3 redhat
   $ htpasswd  -b -B htpasswd-file-upload-anyname user4 redhat
   $ htpasswd  -b -B htpasswd-file-upload-anyname user5 redhat
   $ cat htpasswd-file-upload-anyname

Step-2 Create secret (Type=generic) and hold these information. 
- Inject/update to OpenShift cluster with these information.

  $ oc create secret generic secret-sre-team --from-file htpasswd=htpasswd-file-upload-anyname -n openshift-config 
  $ oc get secret secret-sre-team -n openshift-config 
  $ oc get secret secret-sre-team -n openshift-config -o yaml 
  
Step-3 Update to OAuth.
 $ oc get oauth cluster 
 $ oc get oauth cluster -o yaml 
 $ oc get oauth cluster -o yaml > oauth.yaml  
 $ oc get oauth cluster -o yaml > oauth-bkp.yaml
 $ vim oauth.yaml 
  
Append below points 
- name: my_identity_provider
  mappingMethod: claim 
  type: HTPasswd
  htpasswd:
   fileData:
     name: htpass-secret
	 
	
 $ oc apply -f oauth.yaml 
 $ oc get pods -n openshift-config 
 $ oc login -u user2 -p redhat https://api.ocp4.example.com:6443
